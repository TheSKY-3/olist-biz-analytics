# 简历 bullet 模板（按岗位版本）

> 你可以把下面 bullet 直接粘贴到简历“项目经历”，并按你真实做过的内容微调数字与口径。

---

## Version A：数据分析 / 商业分析（主投）
- 基于 Olist 电商多表数据（订单/明细/支付/评价/客户/卖家/商品/地理）搭建 MySQL 分析库，构建订单级 KPI 宽表与类目月度趋势视图，沉淀 GMV、订单量、AOV、履约延迟、差评率等核心指标体系。
- 使用 Python 实现 ETL 与自动化分析流程（分批导入、时间字段处理、地理表按邮编聚合），输出经营分析报告与可视化图表（趋势/分布/TopN/关联分析）。
- 在 PowerBI 直连 MySQL 语义层，设计并实现经营看板（经营总览、履约 SLA、口碑驱动、商家评分卡），编写 DAX 指标口径与数据说明文档。

## Version B：机器学习 / 算法（偏业务落地）
- 构建履约延迟与差评驱动分析特征（延迟分桶、时效分解、支付结构、地理特征），探索可解释的业务规则与阈值策略，为商家治理与 SLA 优化提供数据支持。

## Version C：数据开发 / 数据工程（补工程化叙事）
- 基于 Docker Compose 搭建 MySQL 数据服务与 Python ETL 容器，完成多源数据落库与语义层（views）建设；沉淀可复用的导入脚本与数据质量校验（可扩展 Great Expectations）。

## Version D：AI 产品 / 产品运营（包装为产品化）
- 以“经营看板”为目标交付物完成需求拆解（指标口径、看板页面、筛选器设计），通过数据分析定位关键问题（延迟与差评相关、慢商家/慢品类），输出可落地优化建议与复盘材料。
